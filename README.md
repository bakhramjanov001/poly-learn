# DeutschMaster UZ

## Purpose
A web flashcard application for memorizing German vocabulary with Uzbek translations, phonetic readings in Uzbek script, audio pronunciation, a daily 50-word goal, custom word entry, and a quiz with grading.

## Who It Is For
Beginners learning German who want structured vocabulary practice, audio and phonetic pronunciation support, daily targets, and self-testing without external accounts or complex setup.

## How to Use
1. Open the app in a browser and flip flashcards to view translations and phonetic readings.
2. Listen to words using normal or slow playback, shuffle cards, or switch between German-to-Uzbek and Uzbek-to-German modes.
3. Add new words individually or in bulk using the add word feature.
4. Start the quiz after memorizing words to get graded results.
5. Check the results dashboard to track your daily 50-word limit, progress, and test history.

## Technologies Used
HTML5
CSS3
Vanilla JavaScript
Web Speech API
localStorage

## Setup
Download or clone the repository and open index.html in a web browser.
