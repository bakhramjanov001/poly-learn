PolyLingua

PolyLingua is an interactive language-learning web application packaged in a single index.html file. Users can memorize words in 20-word sections, listen to pronunciation, take quizzes, manage their own vocabulary lists, and export word lists as PDF files.

Is This a Website or an App?

Right now: It is a website / web application (index.html) that runs directly in a web browser.

Key Features

5 Languages: German (de), Russian (ru), English (en), Turkish (tr), and Arabic (ar).

20-Word Sections & Flashcards: Flip cards, mark words as memorized, shuffle, and switch translation direction.

Pronunciation (TTS): Listen to words at 0.5x, 0.7x, or 1x speed.

Quiz Modes: Typed quizzes (target language to Uzbek and Uzbek to target language) as well as 4-choice quizzes, with a mode to retry mistakes.

Vocabulary Management & PDF Export: Add words (single or bulk), edit, delete, search, and download your vocabulary as a PDF.

Local Storage: Progress, streaks, and vocabulary are saved on the user's device via localStorage.
